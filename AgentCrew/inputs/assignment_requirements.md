# Assignment 3 Requirements

## Assignment

Build an agent crew that produces game-ready output for the student's capstone game.

## Required Deliverables

1. **Crew Code**
   - CrewAI or raw orchestration code.
   - At least three agents must coordinate.
   - The pipeline must run and produce output without crashing.

2. **Mermaid Diagram**
   - Shows agent roles.
   - Shows connections.
   - Shows data flow.

3. **README**
   - Names the game.
   - Explains what the crew produces.
   - Explains how the output connects to the capstone game.

## Grading Criteria

- Working Crew: 3 points
- Game Connection: 3 points
- Role Clarity: 2 points
- Architecture Diagram: 1 point
- README: 1 point

Each agent must have a specific input and output. No agent should be removable without breaking the pipeline.
