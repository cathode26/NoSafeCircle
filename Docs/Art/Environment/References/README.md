# Dungeon visual references

Vincent supplied these 17 images in the September 13, 2026 Codex design
conversation. They were previously temporary clipboard attachments, not files in
this Git project. The numbered PNGs preserve those attachments byte for byte in
the order supplied. They are **design references only**: do not import them into
Unity, ship them, trace them, or copy their assets or layouts. The approved game
direction is [DUNGEON_ART_DIRECTION.md](../DUNGEON_ART_DIRECTION.md); all game art
must be original. The exact upstream source and reuse rights of each screenshot
have not been established.

| Images | Useful design observation |
| --- | --- |
| R01–R03 | Isometric wall and floor rhythm, sparse ritual focus, raised focal structure. |
| R04–R06 | Water-edged room composition, bridge crossing, dense combat-room clutter. |
| R07–R08 | Recognizable furniture at camera scale, authored clutter and route edges. |
| R09–R11 | Modular gothic architecture, tall silhouette landmarks, framed corridors. |
| R12–R15 | Water and bridge routes, room clustering, lived-in interiors, irregular branches. |
| R16–R17 | Dramatic hazard boundaries and gothic destination-room framing. |

Use these as a mood and composition vocabulary. The GDD's approved five-room
blockout and the room task contracts decide actual geometry, doors, and gameplay.
